## Verified defects corrected

1. `TaskSlotWidget.task_qss` had two stacked `@classmethod` decorators. Calling the method therefore attempted to invoke an inner `classmethod` descriptor and raised `TypeError` during `MainWindow` stylesheet construction. v1.0.6.7 retains exactly one decorator.
2. Critical UI events correctly applied bounded-queue backpressure during normal operation, but a full queue could keep a stopping/closing worker inside `emit()` indefinitely. v1.0.6.7 exits that wait only after an explicit stop/close request; persisted runtime results remain authoritative.
3. The pre-Send crash marker already persisted `items.status=interrupted` and `manual_review_required`, but did not immediately upsert the authoritative result ledger. The marker now updates both stores before the Playwright click call.
4. The visible `Send Limit` task metric represented conservative Send-click attempts rather than successful sends. The label is now `Send Attempts / Limit`; counting behavior is unchanged.
5. The supplied v1.0.6.5 source ZIP contained forbidden runtime/private/cache material despite the release-hygiene contract. `scripts/verify_source_archive.py` now rejects such archives, and the clean v1.0.6.7 baseline excludes those paths.

## Preserved scope

No change was made to Licora API v2, `LicenseManager`, P-256/RS256, Share Invite selectors or Send sequence, `ActivationPage`, Browser Settings, `TaskRuntimeStore`, input parsing, concurrent-worker limits, report architecture or visual design foundation.
