# v1.0.6.44 — Final Release Chrome TLS Closure

## Baseline

v1.0.6.43, GitHub main merge `8d76720740f9d822afb7ce5bc4f04f1e2407b5e9`, tree `1fa6033f55e59d7abcdfa1fe62a781edb4024f36`.

## Fix

The Chrome prerequisite downloader no longer depends on the portable `urllib`/OpenSSL default certificate path. It uses the already-required Requests stack with TLS verification explicitly enabled. Redirect following is manual and every target must pass the existing exact `dl.google.com` Stable x64 MSI policy. Authenticode and Google LLC signer verification remain mandatory before execution.

## Frozen

Phase-1/Phase-2 runtime architecture, Plugin API 1, schemas, licensing, power, browser profiles, settings, dependencies, CI and portable packaging architecture are unchanged.
