## Implemented scope

- Atomic workspace metadata persistence using the existing `APP_STATE_FILE` (`AppData/state.json`).
- Automatic restoration of normal active Task cards in saved order with stable slot IDs.
- Latest Target URL persistence even for blank Tasks with no runtime run.
- Existing `TaskRuntimeStore.load_run()` restoration for uploaded data, current index, success/failed/remaining, send-limit and manual-review state.
- Selected application page persistence.
- Workspace size/position/maximized persistence with safe multi-monitor clamping.
- Debounced live saves plus final saves on clean close, logout and license-invalid teardown.
- Workspace-restored run IDs are excluded from duplicate crash-recovery prompts.
- Corrupt/unsupported workspace state is quarantined and falls back safely.
