# v1.0.6.32 — Chrome Prerequisite UX + Secure Install

Phase 2 extends the v1.0.6.31 Chrome-only runtime foundation with a Windows prerequisite recovery flow. VibraPilot checks for a genuine installed Google Chrome runtime at startup, before every new Task browser, and again inside the backend immediately before Playwright startup.

When Chrome is missing, VibraPilot remains usable for non-browser functions but browser automation is blocked. A **Google Chrome Required** dialog lets the operator explicitly choose **Download & Install Google Chrome**, re-check the machine, or defer with **Not Now**. No network download or installer execution occurs without the explicit install action.

The install coordinator downloads the code-owned Stable x64 Enterprise MSI from `https://dl.google.com/dl/chrome/install/googlechromestandaloneenterprise64.msi` using HTTPS with a strict `dl.google.com` host/path policy. The payload is written atomically through a `.part` file, SHA-256 is recorded, Windows Authenticode trust is verified with WinVerifyTrust, and the signer must resolve to **Google LLC**. Only then is the verified MSI launched through elevated Windows Installer (`runas`). UAC cancellation, network failure, invalid signature/publisher, installer failure and post-install Chrome absence are distinct fail-closed states.

After installation, VibraPilot re-runs the v1.0.6.31 Google Chrome product/path/version validation. Successful installer exit codes are not sufficient by themselves. Chromium fallback, custom browser executable selection, sandbox-off operation and unpacked Chromium side-loading remain prohibited.

Build/Nuitka/WiX/package changes remain outside this functional update.
