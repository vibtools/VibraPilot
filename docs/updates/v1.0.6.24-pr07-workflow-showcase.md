# v1.0.6.24 — PR-07 Workflow Showcase Page

PR-07 adds one top-level Workflows page after Tasks and before Workflow Inputs. The page enumerates only `WorkflowManager.list_workflows()` entries, displays manifest name/description/version/workflow ID/logo, shows the persisted active workflow, and fails closed when state or runtime resolution is unavailable.

Activation delegates to `MainWindow.request_workflow_switch()` from PR-06. PR-07 does not duplicate confirmation, clearing, rollback, commit, restart or recovery logic. Production registry remains `share_invite` only.

No dynamic Workflow Inputs, Task/report/database/workspace schema, Browser, licensing, dependency, CAPTCHA or plugin-system changes are included.
