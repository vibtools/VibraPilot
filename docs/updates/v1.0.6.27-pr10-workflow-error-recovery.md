# v1.0.6.27 — PR-10 Workflow Error Handling / Recovery

PR-10 adds explicit fail-closed workflow control-plane recovery without changing Task/database/report schemas, Browser behavior, Share Invite execution, licensing, dependencies or CI. Corrupt/unavailable workflow state and Workflow Input state require explicit user-confirmed recovery; interrupted recovery uses a crash-safe `AppData/WorkflowRecovery/<transaction-id>/` PREPARED/COMMITTED transaction.

Active workflow runtime factories are preflighted before browser creation. Unresolved switch/recovery transactions hard-block automation/recovery rather than being silently deleted. Production registry remains `share_invite` only; PR-11 is not started.
