# v1.0.6.28 — PR-11 E2E Windows / Multi-Task Regression

PR-11 is a verification-first target-Windows acceptance candidate. It adds a resumable sanitized evidence runner, deterministic localhost capability fixtures and a read-only evidence verifier. Production runtime/source, schemas, defaults, dependencies and CI remain frozen.

Mandatory owner acceptance covers browser lifecycle, manual close/crash recovery, downloads/uploads/storage/extensions, 1/2/4-Task isolation, Sandbox OFF/ON compatibility and Chrome identity. Controlled fallback may be explicitly recorded as an owner-accepted residual when it cannot be tested safely.
