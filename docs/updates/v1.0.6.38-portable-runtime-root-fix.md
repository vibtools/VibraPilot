# v1.0.6.38 Portable Runtime Root Fix

## Scope

v1.0.6.38 is a defect-only continuation of the v1.0.6.37 portable release work. The only production source file allowed to change is `src/vibrapilot/runtime_environment.py`.

## Root cause

GitHub Actions Portable Windows Release run `32056816056` built and verified the Nuitka OneDir payload successfully. The startup smoke then exited with code 1. Captured stderr proved that `config/settings.defaults.json` was searched at the parent `release/` directory rather than inside the copied portable folder.

The v1.0.6.37 helper used `__compiled__.containing_dir` as the in-distribution data root. That location is appropriate for finding items near the compiled artifact/dist container, but not for data shipped inside the copied standalone folder. The executable's own directory is the correct program-adjacent root for this OneDir layout.

## Fix

For Nuitka compiled execution:

```python
return Path(sys.argv[0]).resolve().parent
```

PyInstaller continues to use `_MEIPASS`; source execution continues to use the repository root.

No backend, UI, Chrome, workflow, licensing, database, persistence, report, dependency, CI architecture, Nuitka version or WiX/MSI behavior changes.
