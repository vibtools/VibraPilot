# v1.0.6.34 — UI-Only Compact Polish

v1.0.6.34 is a presentation-only update against frozen v1.0.6.33 commit `dc149f768451383747ed02dc96607a4cfb4a3fb2` and clean baseline ZIP SHA-256 `0cf40aac25af1422c945af23d91b0293f41396c24b24ceca9bf556db56bb3f8b`.

## UI changes

- Main workspace page headers now render title + actions without decorative subtitle rows.
- Dashboard metric cards retain names and values while removing helper captions.
- Task cards remove the redundant visible workflow subtitle.
- Workflow showcase uses compact 280–360 px tiles in a responsive 1/2/3-column grid.
- Workflow cards keep logo, name, version/source metadata, availability state and functional actions, while removing manifest description, visible workflow ID rows and duplicate disabled Active buttons.
- Workflow Inputs/Settings remove persistence/isolation prose while preserving selectors, schemas, persistence and recovery behavior.
- Header responsive debug badge and redundant status-bar copy are removed.
- About, Activation and App Settings remove non-essential descriptive copy while retaining actual identity, status, support, validation and safety state.

## Safety boundary

Security, consent, error, warning, validation, empty-state and runtime-evidence text remains visible. Chrome prerequisite/trust policy, licensing, workflow behavior, Task lifecycle, reports/export behavior, persistence, dependencies, CI and build/package surfaces are unchanged.

Workflow cards now use a dedicated 2px tokenized border together with the shared surface and radius tokens so compact tiles remain visually distinct from the workflow page background.

The WorkflowCard surface-separation correction addresses a selector-specific root cause: the compact workflow tile uses objectName `WorkflowCard`, so the generic `QFrame#Card` surface/border rule did not apply after the object name was changed.
