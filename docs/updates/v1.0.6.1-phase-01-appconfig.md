# VibraPilot v1.0.6.1 — Phase-01 AppConfig Centralization

Date: 2026-08-08

## Scope

Phase-01 introduces the internal AppConfig architecture approved for VibraPilot. It centralizes
public/non-secret application identity, About copy, support/documentation URLs and social/community
metadata while preserving the validated v1.0.6.1 runtime.

## Added

- `config/AppConfig/app.py` — authoritative application identity/product metadata.
- `config/AppConfig/about.py` — About-page and company/product presentation copy.
- `config/AppConfig/support.py` — confirmed public support/documentation/project URLs.
- `config/AppConfig/social.py` — public social/community profile metadata.
- `src/vibrapilot/app_config.py` — validated, read-only facade for runtime consumers.
- AppConfig consistency, About binding, support/social and build-binding regression tests.
- Public AppConfig architecture documentation under `docs/configuration/`.

## Changed

- Existing backend application constants now alias validated AppConfig identity values.
- Package `__version__` consumes AppConfig version metadata.
- Windows build name/version consumes AppConfig instead of independent literals.
- Activation/window organization identity and About-page content consume AppConfig while preserving
  the existing visual design, geometry and user-visible values.
- `pyproject.toml` exposes repository/documentation project URLs and remains verifier-synchronized
  with AppConfig.
- Repository verification now checks AppConfig required files, metadata parity and the Phase-01
  licensing boundary.

## Explicitly preserved

- Application version: `1.0.6.1`.
- Licora base URL, API key, verification endpoint and request authentication contract.
- `LicenseManager` behavior and DPAPI storage behavior.
- All `AutomationWorker` methods and implementation behavior.
- Existing selectors and site-specific built-in workflow.
- Browser Settings defaults/runtime mappings.
- Task processing, reports, safety controls, retry behavior and persistence.
- Frozen Vib Tools design-source files and hashes.

## Phase-02 boundary

`licensing_public.py`, Licora API v2, device-bound credentials/tokens and removal of client-side
master API credentials are not part of this update. They are reserved for the separately approved
Phase-02 licensing architecture.
