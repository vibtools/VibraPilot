# v1.0.6.37 Portable Release Packaging

v1.0.6.37 adds the first supported GitHub Actions packaging path for a Windows x64 portable VibraPilot release.

## Scope

- Build with pinned Nuitka 4.1.3 in standalone OneDir mode on Windows + Python 3.12 x64.
- Package `VibraPilot.exe` and its adjacent runtime dependencies into a portable ZIP.
- Keep Google Chrome external; no Playwright Chromium browser is downloaded or bundled. The Nuitka Playwright plugin is explicitly set to `--playwright-include-browser=none` while retaining the Playwright control driver.
- Keep WiX/MSI completely out of scope.
- Preserve the existing browser, workflow, licensing, persistence, Task and report behavior.

## Packaging compatibility shim

Nuitka deliberately does not set `sys.frozen`. VibraPilot therefore centralizes packaged-runtime detection in `src/vibrapilot/runtime_environment.py` so the previous PyInstaller behavior remains compatible while Nuitka standalone uses `__compiled__.containing_dir` for packaged data. The same packaged-runtime predicate protects localhost licensing policy and workflow restart behavior.

## Candidate and release flow

Manual `workflow_dispatch` builds a candidate artifact for owner validation. A `v*` tag rebuilds from tagged source, but publication fails closed unless the tag exactly equals `v{AppConfig.VERSION}`. A valid tag publishes only the portable ZIP plus its SHA-256 sidecar as GitHub Release assets.


## RC defect discovered after implementation

The second manually dispatched RC (`32056816056`) captured the previously hidden startup traceback. The v1.0.6.37 compatibility shim's use of `__compiled__.containing_dir` was incorrect for data files copied inside the final OneDir folder: runtime searched for `release/config/settings.defaults.json` while the verified payload contained `release/VibraPilot-1.0.6.37-Windows-x64-Portable/config/settings.defaults.json`.

This historical defect is superseded by the narrowly scoped v1.0.6.38 runtime-root correction. The v1.0.6.37 packaging architecture itself (Nuitka standalone OneDir, system Chrome only, no Chromium, no WiX/MSI) remains valid.
