# v1.0.6.25 — PR-08 Dynamic Workflow Inputs + Per-Workflow Persistence

PR-08 adds source-controlled declarative Workflow Input schemas and canonical schema-v1 `AppData/workflow_inputs.json` persistence. Existing Share Invite values migrate once from the four historical settings keys when the canonical store is absent; those keys remain compatibility mirrors. The Workflow Inputs page renders the active schema dynamically, Save/Reset affect only the active workflow, and newly created workers receive an immutable validated input snapshot.

Production registry remains `share_invite` only. PR-06 workflow switching, Share Invite runtime, Browser/licensing/CAPTCHA behavior, Task/workspace/report schemas, dependencies and CI workflow remain frozen.
