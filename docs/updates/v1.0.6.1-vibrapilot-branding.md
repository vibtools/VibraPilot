# VibraPilot Branding Baseline on v1.0.6.1

Date: 2026-08-08

## Scope

This update establishes **VibraPilot** as the product identity without changing application workflow behavior. The uploaded v1.0.6.1 project was frozen as the behavioral baseline before the rename.

## Changed

- Product/display/application identity → `VibraPilot`.
- Production package → `src/vibrapilot/`.
- Windows executable/release builder name → `VibraPilot`.
- PowerShell launcher → `scripts/Start-VibraPilot.ps1`.
- Runtime title, activation title/subtitle, About/product metadata and compact window branding.
- Documentation, manifest, citation and project metadata.
- Login/main-window icon presentation and QApplication/titlebar/taskbar icon wiring.
- `assets/icons/` is packaged into the Windows ONEDIR build.

## Preserved

No automation workflow or runtime behavior was changed. In particular:

- existing browser/Playwright settings and browser worker behavior,
- all existing site-specific workflow selectors, URLs and success/error handling,
- Test Mode and send-limit safety logic,
- task lifecycle, retry/backoff and context recycling,
- data import/export, failed/unprocessed persistence and reporting,
- Licora validation mechanics and periodic revalidation, and
- graceful browser/application shutdown

remain the same behaviorally.

## Site-specific naming rule

Third-party site names are no longer used as the product/application identity. Site-specific references remain only where technically necessary to preserve the existing built-in workflow or required third-party attribution. This allows future work to isolate the current workflow as a reusable example/template without falsely claiming that the workflow has already been generalized.

## Icon assets

- `assets/icons/app.ico` — Windows executable/titlebar/taskbar icon
- `assets/icons/app.png` — in-app compact VibraPilot logo
- `assets/icons/logo.png` — full-resolution VibraPilot logo asset retained for documentation/branding use

## Version

Runtime version remains **1.0.6.1** because this is a branding-only baseline transition.
