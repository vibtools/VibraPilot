# VibraPilot v1.0.6.41 — Phase 1 Active-Page Origin Closure

## Scope

This release is a forensic seal over the owner-frozen v1.0.6.40 Phase 1 closure. It does not implement Phase 2.

## Reproduced defect

The deterministic active-page selector compared `(scheme, host, port)` literally. Browser-equivalent origins such as `https://app.example/` and `https://app.example:443/` therefore compared unequal. The same applied to HTTP omitted-port versus explicit `:80`.

With multiple restored/live pages, a target-origin page using the explicit default port could be skipped and the selector could fall through to an unrelated last usable tab.

## Correction

`AutomationWorker._origin_from_url()` now canonicalizes only explicit default ports:

- HTTP `:80` → default/omitted representation
- HTTPS `:443` → default/omitted representation

Non-default ports remain distinct. Malformed explicit ports still fail safe to `None`.

## Frozen behavior

Session policy, background Chrome policy, Windows sleep guard, browser-restart safety, context recycling, UI/UX, workflow/plugin lifecycle, licensing, persistence, dependencies, CI and portable packaging are unchanged.

## Versioning

Phase 2 remains not started and moves to v1.0.6.42 because v1.0.6.41 is consumed by this Phase 1 forensic seal.
