# v1.0.6.30 — Workflow Plugin System

VibraPilot v1.0.6.30 extends the existing one-active-workflow architecture with trusted local `.vpworkflow` packages. Package metadata and UI configuration are declarative; trusted `workflow.py` supplies business automation logic through the existing WorkflowRuntime contract. The Core remains authoritative for Task/browser lifecycle, retry/backoff, persistence/recovery, reports/logs and licensing.

## User-facing changes

- Workflows page: Load Workflow, installed origin/status and activation through the existing atomic switch service.
- Workflow Inputs: workflow selector and richer controlled field types.
- Workflow Settings: new per-workflow settings page with atomic persistence.
- Tasks: compact Core controls plus Task Settings for workflow-controlled Target URL/files/extra fields, Workflow Step and workflow metrics.
- App Settings: user-facing global processing/interface/output paths only; failed/unprocessed-data saving and running-task close confirmation are always enforced.

## Deferred

Per-Task mixed workflows, JSON Playwright interpretation, marketplace/remote install, plugin sandboxing, automatic dependencies, arbitrary plugin UI and automatic plugin update/uninstall are not implemented.
