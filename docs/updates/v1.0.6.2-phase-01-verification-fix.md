# VibraPilot v1.0.6.2 — Phase-01 Forensic Verification and Completion

Date: 2026-08-08

## Scope

This release is limited to verification and completion of the previously approved Phase-01 AppConfig architecture. It does not implement Phase-02 licensing architecture or Licora API v2.

## Root causes found

1. **Stale pre-rebrand active paths survived a local overwrite-only merge.** `src/tester_zepto_pro/` and `scripts/Start-TesterZeptoPro.ps1` were present even though the existing repository branding/verification contract requires them to be absent. The duplicate legacy backend also carried the current embedded Licora credential and caused the repository secret-hygiene scan to fail before the explicit stale-path check.
2. **Support/social configuration was incomplete.** The Phase-01 support module left the confirmed public support/contact values blank, contained an unverified developer-portal value, and the social module exposed only GitHub even though the official Vib Tools website publishes additional public profiles.
3. **Validation was only partially implemented.** Date validation checked shape but not calendar validity; version shape was not validated; required metadata sequences were not validated item-by-item; and social `enabled` values were coerced with `bool(...)` instead of requiring a real boolean.

## Fixes

- Removed the stale active pre-rebrand source package and launcher while retaining private historical baselines under gitignored `project/`. The release delta includes `scripts/maintenance/Apply-v1.0.6.2-Phase01-Fix.cmd` because ordinary ZIP overwrite cannot delete stale paths.
- Set the confirmed public support address to `support@vib.tools` and contact endpoint to `https://vib.tools/contact`.
- Cleared the unverified developer-portal field instead of inventing or retaining an unsupported endpoint.
- Added the official Vib Tools public social profiles linked from `https://vib.tools/`: GitHub, X, Facebook, Instagram, Reddit, TikTok and GitLab.
- Completed the approved About/company metadata fields without inventing an unverified legal name or support-team name; those optional fields remain blank until authoritative values exist.
- Added strict validation for real ISO calendar dates, numeric release versions, required metadata sequences, optional support email format, social booleans and enabled-social URLs.
- Kept the About-page visual structure intact while binding the completed company/support/social values.
- Promoted synchronized release metadata to **1.0.6.2**.

## Explicitly unchanged

- Licora v1 API base URL, API key, verification endpoint and request authentication contract.
- `LicenseManager` implementation and DPAPI storage behavior.
- `AutomationWorker` implementation, selectors and the built-in workflow.
- Browser Settings defaults/runtime mappings.
- Task processing, reporting, safety controls, retry/persistence behavior.
- Frozen Vib Tools design-source files and hashes.
- Phase-02 `licensing_public.py` and Licora API v2 remain unimplemented.
