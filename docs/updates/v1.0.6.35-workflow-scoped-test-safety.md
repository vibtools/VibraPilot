# v1.0.6.35 — Workflow-Scoped Test Safety Isolation

## Root cause
The original single-workflow Razorpay Test Mode safety controls remained global after VibraPilot became a multi-workflow host. `TaskSlotWidget.start()` therefore blocked every workflow when the legacy `authorized_testing_only` setting was false.

## Change
- Remove the global App Settings Test Safety card and global authorization Start gate.
- Add `Max Test Send Limit` to Share Invite Workflow Settings.
- Migrate the previous global send-limit value once unless a namespaced Share Invite value already exists.
- Resolve runtime send limits from immutable workflow settings snapshots.
- Use workflow-neutral Core session wording.
- Preserve Share Invite's live Test Mode banner checks and pre-Send assertion unchanged.

## Frozen boundaries
Chrome/browser identity, licensing, persistence/database schema, plugin API, dependencies, CI and build/package files are unchanged.
