# Browser Settings A–Z Runtime Binding Audit — v1.0.6.1

Release date: 2026-08-07

This document is the per-control forensic map for the advanced Browser Settings page. Every editable control below is persisted through `SettingsManager` and has a concrete browser/runtime consumer. Lifecycle-specific controls are not presented as immediately live when Chromium/Playwright requires a browser or context restart.

**Editable Browser Settings:** 147

Removed from the editable Browser Settings surface because they were duplicate, legacy-hidden, or not real general controls: `hardware_acceleration_enabled`, `disable_image_font_media_loading`, Safe Browsing policy, Password Manager policy, Autofill policy, raw platform spoofing, screen-color-depth spoofing, Origin Trials, and the former informational/read-only cards.

## Apply semantics

- **Runtime / workflow**: saved settings are synchronized to active workers; live Playwright setters/handlers are used where supported.
- **Next context/recycle**: the persisted value is authoritative and applies on BrowserContext creation or recycle.
- **Next browser launch**: Chromium process arguments/options cannot be mutated in place; the persisted value applies when the browser is next opened.
- **Next persistent session**: persistent-profile options apply to the next `launch_persistent_context()` lifecycle.

## Runtime-authority corrections in v1.0.6.1

- **Allow Popups** now overrides Playwright Chromium’s built-in `--disable-popup-blocking` default instead of merely displaying a setting.
- **Background Throttling Enabled** now overrides Playwright’s background-throttling-disabling default flags.
- **Extension Loading** now suppresses Playwright’s default `--disable-extensions` argument and selects Playwright’s full `chromium` channel for persistent extension sessions when no custom executable is supplied.
- **DevTools Auto Open** maps to Chromium `--auto-open-devtools-for-tabs`; the removed Playwright 1.61 `launch(devtools=...)` keyword is not used.
- **Audio Enabled** now filters Playwright’s automatic headless `--mute-audio` default when ON and explicitly mutes Chromium when OFF.
- **Allow Bundled Chromium Fallback** now covers persistent Chrome-channel launches as well as normal launches.
- **Restore Previous Browser Session** is validated as persistent-context-only and requires a profile that persists between app runs.
- **GPU / Hardware Acceleration Enabled** is the single authoritative GPU control; the duplicate hardware alias was removed with migration.
- **Block Images / Fonts / Media** are the only active resource-blocking controls; the hidden combined legacy key is removed after migration.
- Browser Settings refresh from `SettingsManager` on page navigation, successful save, and reset, so the UI shows persisted backend values rather than stale widget state.
- Window X/Y position overrides are validated as a pair so the UI cannot save a coordinate that the backend would silently ignore.

## Non-settings intentionally excluded

Chrome enterprise/profile policy features without a stable general Playwright/Chromium configuration contract are documented rather than exposed as fake toggles. Low-level supported customization remains available through persistent profiles, Additional Chromium Arguments, Browser Environment Variables, and Chrome/Blink feature lists.
