# v1.0.6.29 — PR-12 Packaging

PR-12 migrates Windows x64 packaging to a dedicated GitHub Actions build using CPython 3.12.10 + Nuitka 4.1.3 standalone OneDir, bundles the Playwright Chromium fallback, creates a portable ZIP, and authors a WiX Toolset 6.0.2 per-user MSI. WiX is provisioned only in the ephemeral GitHub runner; no EULA/license acceptance is automated. The PC downloads the generated workflow artifact and performs install/runtime acceptance only.
