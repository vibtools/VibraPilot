## Confirmed v1.0.6.18 verification/fix findings

### F-001 — Playwright runtime dependency mismatch

**Status:** CONFIRMED by captured Windows diagnostics.

**Observed:** runtime `1.60.0`, project requirement `1.61.0`.

**Fix:** diagnostics now classify and warn about expected-vs-actual version mismatch. Project dependency declarations are unchanged because they already specify `1.61.0`.

**Operational remediation:** reinstall exact project dependencies before production acceptance.

### F-002 — raw fallback diagnostic reason

**Status:** CONFIRMED by source inspection.

`build_browser_diagnostics()` persisted the exception-derived `fallback_reason` without diagnostic-text sanitization.

**Fix:** secret-bearing switches and proxy credentials are redacted before persistence/logging.

### F-003 — nested evidence type coercion

**Status:** CONFIRMED by source inspection and v1.0.6.18 evidence.

Nested launch values were stringified by `sanitize_launch_kwargs()`. The real v1.0.6.18 evidence shows viewport width/height as strings under the launch kwargs.

**Fix:** recursive JSON-safe sanitization preserves booleans/numbers.
