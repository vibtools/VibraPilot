# PR-12 Packaging Verification

Acceptance is split: GitHub Actions performs source/package verification and the real Windows x64 Nuitka/WiX build; the owner PC downloads the artifact and performs portable launch plus MSI install/runtime/uninstall acceptance. The Windows verifier must confirm Nuitka OneDir output, required resources, bundled Chromium fallback, portable ZIP integrity, WiX 6.0.2 MSI build/validation, isolated install/launch/uninstall and preservation of untracked runtime/user-data markers. PR-13 automation remains out of scope.
