## Windows compatibility correction

A Windows-only historical Qt lifecycle test exposed a compatibility assumption in `TaskSlotWidget`: lightweight test hosts do not implement `MainWindow.workflow_test_send_limit()`. The Task widget now resolves the real MainWindow method when available and falls back only for lightweight compatibility hosts; non-Share workflows still resolve to zero when `uses_test_send_limit` is false.
