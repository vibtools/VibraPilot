## Scope verification

`config/verification/production_mt_lr_v1.0.6.5_scope.json` records the approved runtime surface, approved parameters and frozen out-of-scope hashes. Verification rechecks the unchanged Licora API v2/client configuration, `LicenseManager`, selectors, `ActivationPage`, Browser Settings contract, design-system sources and every pre-existing settings default other than the approved new `max_concurrent_tasks` setting.

## Functional verification targets

The production test suite covers:

- per-task recipient/run isolation;
- 100,000-recipient mocked sequential processing without index/count drift;
- functional batch checkpoint boundaries and timed autosave wiring;
- crash/restart recovery and completed-run suppression;
- manual-review skip without automatic retry of ambiguous Send outcomes;
- latest-outcome result upsert and per-task filtering;
- successful/failed Browser Context recycle accounting;
- worker stopped-event and UI live-reference retention after cleanup timeout;
- bounded 4096-event UI queue and 250-event-per-tick drain contract;
- input source/valid/invalid/duplicate/accepted reconciliation;
- existing Phase-02 licensing, feature-parity, browser/runtime, branding and safety tests.

## Automated gate

The final release gate requires all of the following to pass on the updated source tree:

```text
python -m compileall -q .
python scripts/verify_repository.py
python -m pytest -q
python -m unittest discover -s tests -p "test_*.py" -v
```

The delivered delta is additionally checked for ZIP integrity, forbidden runtime/private paths and exact replacement simulation against the frozen baseline.

## Platform boundary

Automated mocked/contract tests do not substitute for a supported Windows production smoke test. Before distributing a Windows executable release, run the application on Windows 10/11 x64 with Python 3.12/build dependencies and verify launch, Licora activation/session restore, multiple task browser ownership, recovery, controlled Test Mode processing, logout/shutdown and PyInstaller packaging.
