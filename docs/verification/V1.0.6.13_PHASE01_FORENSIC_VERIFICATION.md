## Root cause classification

### F-001 — Fixed 15-second concurrency threshold

Status: **CONFIRMED**

The failing test hard-coded `thread.join(timeout=15)` even though it validates isolation/correctness, not a production throughput SLA.

### F-002 — Secondary `WinError 32`

Status: **CONFIRMED SECONDARY SYMPTOM**

The test left the `with TemporaryDirectory()` block after the timeout assertion while a writer thread was still alive. Windows therefore blocked deletion of the open SQLite file.

### F-003 — Phase-01 browser runtime regression

Status: **NOT FOUND**

The complete pytest suite passed on the GitHub Windows runner, including all v1.0.6.12 browser lifecycle tests.

### F-004 — Uploaded baseline release hygiene

Status: **CONFIRMED PACKAGING MISMATCH**

The user-frozen ZIP includes runtime/cache/private-development material. It is usable as a forensic development baseline but not as a clean public source artifact.
