## Runtime surface

Only `vib_validation_app/focus_manager.py` may change. The scope manifest freezes backend, Qt application pages, licensing, browser/task/workflow/runtime-store modules, settings, CI/build inputs, all other design-system modules and the frozen token JSON.

## Required invariants

1. A deleted Qt C++ widget wrapper is never dereferenced by focus property/style logic.
2. A delayed tooltip callback safely returns when its widget has been deleted.
3. Stale retained focus state is cleared on `Destroy`/`DeferredDelete`.
4. Live widgets retain the exact `keyboardFocus` property and style repolish behavior.
5. There is no broad exception swallowing; only a deleted-object `RuntimeError` is contained after a failed lifetime check.
6. No new dependency is added; `shiboken6` is part of the existing PySide6 installation.
