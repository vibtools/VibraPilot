## Audit findings

- **Startup blocker:** duplicate `@classmethod` on `TaskSlotWidget.task_qss` deterministically raises `TypeError` when the startup stylesheet calls `TaskSlotWidget.task_qss()`.
- **Shutdown liveness defect:** a saturated critical UI queue can keep `AutomationWorker.emit()` waiting after an explicit stop/close request.
- **Crash-ledger mismatch:** the conservative pre-Send crash marker updates the item/checkpoint state but did not immediately update the authoritative results ledger.
- **UI semantics mismatch:** the Send counter is conservative Send-click attempts but was visibly labeled only `Send Limit`.
- **Packaging mismatch:** the uploaded source ZIP contains gitignored `AppData`, Logs, private `project/` material and Python caches, contrary to the v1.0.6.5 release-hygiene contract.

## Fix scope

The current fix boundary is machine-locked by `config/verification/v1.0.6.7_vp_prod_mt_lr_verification_fix_scope.json`. Runtime changes are limited to `backend.py` and `qt_app.py`; a standard-library source-archive verifier, regression tests, version metadata and synchronized documentation are added.

## Preserved architecture

Licora API v2, `LicenseManager`, selectors, Share Invite Send sequence, Browser Settings, `ActivationPage`, `MainWindow`, `TaskRuntimeStore`, input parsing and all non-approved `AutomationWorker` methods remain frozen by file/AST contracts.
